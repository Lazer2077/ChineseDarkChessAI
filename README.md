# Chinese Dark Chess AI

**简体中文** | [English](README.en.md)

研究全盘**揭棋（Jieqi）**中的不完全信息搜索与自我博弈学习。目标是在可复现、规则兼容的实验中，争取超过公开可运行的独立揭棋引擎。项目采用 GPL-3.0；引用的引擎、模型和规则分别注明来源。

**已在固定规则与实际时钟下完成对三个指定对手版本的双组确认；这不证明训练优于上游教师，全面覆盖仍未完成。** 本项目侧重算法和实验证据；半盘翻翻棋（Banqi）不在研究范围内。

## 问题：隐藏棋子与私人信息

揭棋更准确地属于双人零和部分可观测随机博弈。固定对手策略后，可将单方决策建模为 POMDP；单方规划的最优性不能直接解释为双方博弈的均衡保证。

玩家的信息历史由公开棋盘、揭子与着法历史，以及自己吃到的暗子身份组成。暗子被吃时，身份只告知吃子方。对手吃走而己方未知的棋子仍须保留在未知库存中，不能利用模拟器的真实状态排除。隐藏身份按库存**无放回**分配，棋子之间相关。

当前原型与适配器隔离真实状态和玩家观察，测试隐藏身份不变性、私人暗俘可见性及完整历史重建。现有库存信念并未完整建模“对手着法如何透露其私人信息”；这是研究缺口，不能将其称作精确后验。


## 当前方法：搜索引导的价值学习

主实验基于 [devinokeefe/jieqi](https://github.com/devinokeefe/jieqi) 的固定 MIT 版本：alpha-beta/PVS 搜索、揭子机会分支近似和 NNUE 价值网络。原生搜索架构、训练器与初始教师权重归属上游，见[来源记录](docs/PROVENANCE.md)。当前控制模型为 387,089 参数。

学习循环为：当前模型引导自我博弈 → 收集搜索分数与终局结果 → 最近两轮数据回放 → GPU 更新价值网络 → 独立配对对赛 → 通过门槛后更新下一轮对弈模型。资源截断或错误对局不进入该训练集。若候选未通过门槛，继续保留旧模型，并记录失败结果。

对行动方视角的搜索分数 s 和终局结果 z∈{−1,0,1}，训练目标为：

```math
y = \lambda\,\sigma(s/K) + (1-\lambda)\,(z+1)/2,\qquad
\mathcal L = \mathbb E[(\sigma(V_\theta(o)/K)-y)^2].
```

本轮采用 λ=0.7、K=430。这是包含搜索目标蒸馏和终局结果学习的价值型 expert iteration。另已实现[残差策略价值网络＋信息集PUCT的自我博弈RL](docs/NEURAL_SELFPLAY.md)，以真实访问分布和终局奖励更新当前模型，完成16局流程试验，三轮连续学习正在进行；首轮对更新前模型为24胜1和39负，对原始教师为1胜0和63负，均无技术错误，尚无棋力增益证据，也未实现完整POMCP、CFR或ReBeL。早期 15 维线性策略原型仅用于验证观察隔离和搜索训练流程，不代表当前主实验棋力。

- [三种子 NNUE 系列](results/20261026-continual-three-seeds.json)已完成：每种子两轮、每轮8,192局，合计 **49,152局、3,618,389条原始搜索局面**，生成拒收对局0。每轮GPU训练15 epochs；六轮各200局内部门槛赛得分为46.75%、47.75%、50.0%、55.75%、50.75%、46.5%，均未满足晋级标准。因此所有生成仍由原教师引导，不能宣称成功迭代出更强行为策略。
- NNUE训练使用GPU，自我博弈搜索主要使用CPU。另已完成两张GPU各自独立训练的约934万/1,007万参数策略价值对照，每组12 epochs、56,652次更新；这是教师监督预训练，不是多卡分布式训练，也不代表AlphaZero规模或强化学习棋力成果。
- 从头训练的小数据模型对教师：7胜0和25负；揭子方差分配搜索改动对原版：14胜2和16负。均未晋级。
- 初次热启动模型在 32 局开发赛为18胜1和13负；独立确认 A 为 **95胜10和95负（50%得分）**，并有一次时间判负，未满足技术完整性门槛。开发集优势未获该确认集支持；确认 B 已完成77胜17和106负（42.75%），亦有一次时间判负；两组确认均未支持晋级。
- 原始 C++ Mist 引擎已在其原始规则配置下接入，完整保留玩家私人历史；随后16局开发赛为 **15胜0和1负（93.75%）**，无无效局，但仅8对布局，且采用集成试跑的计时容差，仍不支持正式优势声明。结果与其 JS 引擎分开报告。后续实际时钟首组200局为192胜8负，但含4次对手超时，未通过预定技术完整性门槛；第二组已完成191胜9负，含3次对手超时；两组均不支持正式优势声明。

- Yuan-Bai/jieqi-lab 的纯 ISMCTS 配置另完成两组各200局，均为200胜、无技术错误，11,624步重放通过；该项目的神经模型配置尚未验证，因此项目整体仍不标为击败。增强版 Pika 的高分确认赛存在计时取整歧义，Hefeng 混合版存在引擎退出无效尝试，均未通过确认。

- AB-JChess 的[四组对照](docs/ABJ_CONFIRMATION.md)均已完成：同布局原始教师在 A/B 组分别得分75.5%和79.5%。训练模型相对教师的合并差值为+1.625个百分点，探索性配对95%区间[-3.125, +6.25]包含零，**未确认训练增益**。开发赛不与确认赛合并。

原始对局压缩记录、校验和及报告见 [results](results)；[新一轮检索审计](docs/DISCOVERY_AUDIT.md)补入了遗漏来源；[对手清单](docs/opponents.json)同时保留未测、不可用和规则不兼容的项目。不同规则、时限或引擎版本的结果不合并计算。

Musesfish 的[实际时钟兼容配置](docs/MUSESFISH_CLOCK.md)已完成两局接入检查及32局开发赛，候选均获胜，1,397 步及计时重放无误；双组确认尚待完成，不能据此宣称棋力优势。

## 正在检验的假设

**容量是否限制价值学习？** 将同一教师函数扩展到约164万及1,345万参数，分别增加网络宽度和己方将位特征桶。初始化在256组配对输入上的最大输出偏差为9.54×10⁻⁷，六个固定深度原生基准的着法、分数和节点数一致。三个规模使用同一批完整训练数据、固定验证数据与学习配方；随后以相同实际时钟检验收益能否抵消推理成本。初始化等价不意味着训练后更强。首个164万参数模型对同数据训练的小模型为27胜1和36负，64局得分42.97%，配对bootstrap 95%区间[32.81%, 53.13%]，无技术错误，尚无容量收益证据；1,345万参数模型对同一小模型为26胜2和36负，亦未支持收益。

**机会分支预算是否应按不确定性分配？** 已测试按 pᵢ(vᵢ−E[v])² 分配额外深搜的变体，当前没有优于原版的证据。后续应区分身份结果方差、价值估计误差和真正会改变根动作的决策不确定性，而不能仅因揭子结果差异大就增加预算。

**训练应怎样分配不同信息阶段的权重？** 已完成[四组回放损失加权](docs/REPLAY_WEIGHTING.md)的 GPU 训练，每组使用同样的8,192局来源、405,959个保留局面与1,485次更新；比较局面等权、每局等权、全局阶段等权，以及每局内阶段等权。等权控制组导出网络与此前实验逐字节一致；三组各64局固定开发赛分别得分38.28%、49.22%和46.09%，均未证明棋力收益。

**扩大残差网络能否突破胜率瓶颈？** [模型规模实验方案](docs/MODEL_SCALING.md)已将加宽、加深网络和 GPU 训练纳入后续受控实验。当前 934 万参数中约 735 万属于策略输出层，总参数量不能直接代表主干容量。实验将同时比较验证质量、推理成本和相同实际用时下的配对棋力；64/128 通道 GPU 对照已启动，以等价初始函数和相同数据、更新次数比较；训练及后续配对棋力测试尚未完成，尚无容量收益证据。

**独立策略头与阶段价值专家能否改善学习？** 新增[残差策略—价值对照](docs/NEURAL_POLICY_PHASE.md)：15个残差块、64通道，共享价值模型约934万参数，公共暗子归零后切换价值MLP的专家模型约1,007万参数。两组已分别在GPU上完成12轮预训练，使用约242万条教师搜索局面；策略标签是真实选中着法，不伪造访问分布。该阶段是监督预训练。三组各64局的实际时钟开发赛均已结束：两模型对教师均为0胜2和62负；阶段模型对普通模型为32胜10和22负（57.81%得分，配对95%区间[46.09%,69.53%]），未确认收益。后续自我博弈RL单独报告，选择验证误差不作为棋力证明。

**仅靠库存与当前棋盘是否丢失重要信息？** 后续比较库存编码与历史/私人信息编码，并检验策略条件信念更新。在同一信息集中约束动作一致性，避免将采样世界中不可见的身份当作行动依据。此项仍是研究方向，尚无完成的强度结果。

**时间差分目标能否改善学习？** 已启动[同一玩家观察下的两步目标消融](docs/TEMPORAL_TARGETS.md)，以未来同一玩家的搜索值部分替代高方差的终局标签，保持控制组数据、初始化和验证目标一致。该方法不直接混用对手私人观察的价值。首个64局开发赛为34胜2和28负，得分54.69%，配对95%区间[42.19%, 66.41%]仍包含50%；对原始教师的首组200局确认赛为98胜11和91负（51.75%，区间[45.75%, 57.75%]），仍未确认增益；第二组为93胜13和94负（49.75%，区间[43.5%, 56.0%]），同样未支持晋级。

**从部分可观测到全明的过渡能否利用？** 已加入[信息阶段研究](docs/PARTIAL_TO_FULL.md)：用无放回库存的联合熵区分公共确定性和玩家私有确定性，并已实现“全部暗子消失后忽略无关离盘库存”的 NNUE 训练与搜索消融。语义与增量更新一致性已验证；仅改推理的64局对照为29胜6和29负，尚无棋力收益，匹配重训后为30胜7和27负（52.34%，配对95%区间[42.19%, 62.5%]），同样未确认收益。

## 文献与方法边界

- [Silver et al., AlphaZero, Science 2018](https://doi.org/10.1126/science.aar6404)：借鉴自我博弈、搜索改进和学习的循环。揭棋的私人信息使直接套用完全信息状态搜索存在问题。
- [Silver & Veness, POMCP, NeurIPS 2010](https://papers.nips.cc/paper_files/paper/2010/file/edfbe1afcf9246bb0d40eb4d8027d90f-Paper.pdf)：借鉴历史树、根信念采样和模拟器规划；应用到固定对手与双方自我博弈时需分别讨论假设。
- [Brown et al., ReBeL, NeurIPS 2020](https://arxiv.org/abs/2007.13544)：研究公共信念与搜索学习结合，提醒我们处理双方私人信息及策略依赖。本文的收敛保证不自动适用于本项目的近似搜索和函数逼近实现。

遇到训练停滞，将优先检验数据覆盖、目标偏差、信念表示及搜索成本，围绕上述文献提出可证伪的消融实验；增加训练时长或模型大小本身不视为创新。

## 评测标准

最终报告门槛：对届时检索核实的全部开源及研究强基线，允许单一训练种子，在多个独立测试种子的换色布局集上稳定达到70%以上**胜率**（胜局/总局数，另报含和棋的得分率），再撰写含训练曲线、核心创新、消融及关键实现细节的arXiv风格技术报告。现有版本级优势确认尚未达到此目标；完整验收条件见[持续目标](docs/GOAL.md)。

预先固定模型、版本、布局种子、规则、时钟、线程和样本量，训练布局与评测布局分离。正式优势判断至少需要100对布局换色，报告W/D/L、得分率、按布局配对的95% bootstrap区间，以及所有超时、非法着法、无效和截断对局。内部晋级另要求保守的有界均值下界超过50%，且无技术错误；总体优势还需用同一冻结模型在多个独立测试种子的布局集上确认，不要求多个训练种子通过。单训练种子的结论限定于所测模型，不据此宣称跨训练初始化稳定。

等实际时间与等节点预算分别研究；更大的网络不能仅凭等节点优势宣称等时间更强。不得改弱对手、替换其正式网络或用JS版本代表其C++引擎。规则差异由独立裁判和单独配置处理，见 [Mist 原生配置](docs/MIST_NATIVE.md)。
